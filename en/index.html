Backend / High load

Go High-Load Wallet

A Go wallet that moves balances over HTTP and an SQS queue without giving up its guarantees: money stored as integers, idempotency keys, an append-only ledger and a transactional outbox, checked with property-based and linearizability tests. Every phase is measured with k6: 392 req/s with a 30 ms p99 and zero 5xx errors on a 4-vCPU laptop. A React console follows the API live and runs load tests that reconcile the money at the end.
